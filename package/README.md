# 千盈传送

> 临时救场，收发文件，一个网页搞定！

## 介绍

微信传不了？U 盘找不到？发个链接，对方浏览器打开就能收。基于 WebRTC P2P 直连传输，文件不经过服务器。单文件大小可在传送设置中自定义（默认 50MB，最大 2GB，建议不超过 500MB），跨公网传输优先 NAT 穿透直连、失败自动降级 TURN 中继。跨平台支持 iOS / Android / Windows / macOS。

## 核心特性

- **零安装**：纯浏览器使用，无需任何客户端
- **P2P 直传**：WebRTC 点对点传输，充分利用内网带宽
- **跨平台**：iOS、Android、Windows、macOS 全支持
- **相册保存**：图片和视频可保存到手机相册（需开启 HTTPS 反代）
- **内置反代**：自带反向代理，搭配飞牛 DDNS 域名即可从外网访问
- **自动证书**：自动复用飞牛 NAS 系统证书，开箱即用
- **主题适配**：跟随飞牛系统自动切换明暗模式
- **双架构**：x86 与 ARM 双架构支持

## 安装说明

### 1. 通过飞牛应用中心安装

将 `fn_qycs.fpk` 上传到飞牛 NAS，在应用中心手动安装。

### 2. 安装配置

安装时设置服务监听端口（默认 `5553`），安装完成后飞牛会自动启动服务。

## 使用说明

### 局域网传输

1. 同一局域网内，发送方和接收方都打开浏览器访问 `http://NAS_IP:5553`
2. 发送方拖入文件或点击选择
3. 选择右侧在线设备作为接收目标
4. 点击发送，接收方确认即可

### 公网访问（可选）

如果需要从外网访问，或让手机端保存图片/视频到相册：

1. 打开应用桌面图标，进入「公网访问配置」
2. 配置 HTTPS 端口（默认 `7753`）
3. 选择飞牛已签发的域名证书
4. 确保路由器已配置 HTTPS 端口的端口转发

> **重要提示**：iPhone / Android 在非 HTTPS 环境下，浏览器会禁止网页将图片、视频保存到相册。只有开启 HTTPS 反向代理后才能保存。

> **跨网传输（暗号房间）说明**：跨网络互传依赖 WebRTC 穿透。本应用设计上**默认不走 TURN 中继**，仅启用公共 STUN 服务器。
> - 若收发双方均处于**对称型 NAT** 或严格防火墙环境，**仅靠 STUN 无法穿透，跨网互传不被支持**（前端会明确提示「不支持 TURN 中继互传」并阻止发起）。
> - 如需在对称型 NAT 下跨网互传，可在「传送设置」中配置 TURN 中继服务器（支持自建或免费申请），应用会自动按需使用。
> - 应用会在房间内对双方网络能力做**真实校验**，只有在确实具备公网直连或 TURN 中继时才允许跨网传输；否则请双方改为同一局域网或连接同一热点/WiFi 后直接互传。

## 技术原理

```
发送端 ──WebSocket 信令── 服务器 ──WebSocket 信令── 接收端
   │                                                     │
   └────────────── WebRTC DataChannel ────────────────────┘
                     文件数据直传
```

- WebSocket 用于设备发现和信令交换
- 文件数据通过 WebRTC DataChannel 点对点直传
- 服务器不参与文件传输，不占用 NAS 带宽

## 常见问题

**Q: 为什么接收方看不到发送方？**
A: 确保双方都在同一局域网，且都通过浏览器打开了同一个地址。防火墙或网络隔离可能会影响设备发现。

**Q: 图片/视频无法保存到手机相册？**
A: 手机浏览器需要 HTTPS 环境才能写入相册。请在「公网访问配置」中开启 HTTPS 反向代理。

**Q: 传输速度慢？**
A: P2P 直传速度取决于局域网络状况。Wi-Fi 下通常可跑满内网带宽，单文件 ≤ 50MB 通常几秒传完。

**Q: 跨网互传时连接不上（对称型 NAT / 严格防火墙）？**
A: 本应用会优先尝试 STUN NAT 穿透直连，若直连失败会自动降级走 TURN 中继兜底。若未配置 TURN 服务器，对称型 NAT 下跨网互传可能无法建立连接。解决方式：
- 在「传送设置」中配置 TURN 中继服务器（支持自建，或到 metered.ca 免费申请）；
- 或将双方改为同一局域网 / 同一热点后直连传输。

**Q: 移动端下载大文件（>100MB）失败，文件大小为 0？**
A: 这是当前浏览器的技术瓶颈，非应用 Bug。移动端浏览器在处理超大 Blob（>100MB）时内存不足，导致保存到相册或下载时 Blob 文件大小为 0，下载 100% 失败。PC 端不受此限制。建议传输超过 100MB 的文件时使用 PC 端接收。
