# 千盈传送

> 临时急救传文件专用，浏览器打开就能用，无需安装任何客户端

## 介绍

同事急着要个大文件，U 盘找不到，微信又传不了 —— 打开浏览器就能传。WebRTC P2P 直传，文件不走服务器中转，内网速度拉满。跨平台支持 iOS / Android / Windows / Mac，对方也不用装 APP，省去一切折腾。

## 核心特性

- **零安装**：纯浏览器使用，无需任何客户端
- **P2P 直传**：WebRTC 点对点传输，充分利用内网带宽
- **跨平台**：iOS、Android、Windows、Mac 全支持
- **相册保存**：图片和视频可直接保存到手机相册（需开启 HTTPS 反代）
- **内置反代**：自带反向代理，配飞牛 DDNS 域名即可外网访问
- **证书省心**：证书直接用飞牛 NAS 里签发的，不用另外折腾
- **主题适配**：跟随飞牛系统自动切换暗色 / 亮色
- **双架构**：x86 和 ARM 都支持

## 安装说明

### 1. 通过飞牛应用中心安装

将 `fn_qycs.fpk` 上传到飞牛 NAS，在应用中心手动安装。

### 2. 安装配置

安装时设置服务监听端口（默认 `5553`），安装完成后飞牛会自动启动服务。

## 使用说明

### 局域网传输

1. 同一局域网内，发送方和接收方都打开浏览器访问 `http://NAS_IP:5553`
2. 发送方拖入文件或点击选择
3. 选择右侧在线设备作为接收目标
4. 点击发送，接收方确认即可

### 公网访问（可选）

如果需要从外网访问，或让手机端保存图片/视频到相册：

1. 打开应用桌面图标，进入「公网访问配置」
2. 配置 HTTPS 端口（默认 `7753`）
3. 选择飞牛已签发的域名证书
4. 确保路由器已配置 HTTPS 端口的端口转发

> **重要提示**：iPhone / Android 在非 HTTPS 环境下，浏览器会禁止网页将图片、视频保存到相册。只有开启 HTTPS 反向代理后才能保存。

## 技术原理

```
发送端 ──WebSocket 信令── 服务器 ──WebSocket 信令── 接收端
   │                                                     │
   └────────────── WebRTC DataChannel ────────────────────┘
                     文件数据直传
```

- WebSocket 用于设备发现和信令交换
- 文件数据通过 WebRTC DataChannel 点对点直传
- 服务器不参与文件传输，不占用 NAS 带宽

## 常见问题

**Q: 为什么接收方看不到发送方？**
A: 确保双方都在同一局域网，且都通过浏览器打开了同一个地址。防火墙或网络隔离可能会影响设备发现。

**Q: 图片/视频无法保存到手机相册？**
A: 手机浏览器需要 HTTPS 环境才能写入相册。请在「公网访问配置」中开启 HTTPS 反向代理。

**Q: 传输速度慢？**
A: P2P 直传速度取决于局域网络状况。Wi-Fi 下通常可跑满内网带宽，千兆有线可达 900 Mbps+。
